# 🎨 Gerador de Números em Círculo

<img src="https://github.com/souzaseven/geranumero/blob/Desafios/geranumero.png?raw=true" width="50%" alt="Preview">

> Ferramenta web para criação de imagens personalizadas com números em círculos coloridos

## ✨ Funcionalidades
- **Geração em tempo real** de imagens
- **Totalmente personalizável**:
  - Qualquer número (0-∞)
  - Seletor de cores para círculo
  - Seletor de cores para número
- **Multi-formatos**:
  - Download como PNG (imagem)
  - Download como ICO (ícone)
- **Responsivo** - funciona em qualquer dispositivo
- **Ajuste inteligente** de tamanho de fonte

## 🛠 Tecnologia
Tecnologias principais:
- HTML5 Canvas
- Vanilla JavaScript
- CSS Flexbox

🚀 Como usar
Insira o número desejado
Selecione as cores:
Cor do círculo
Cor do número

Escolha o formato: <br>
📥 Baixar como PNG <br>
💾 Baixar como ICO
